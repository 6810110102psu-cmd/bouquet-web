# bouquet-web
#  Bouquet Web - ระบบจัดช่อดอกไม้ออนไลน์

ชื่อ-สกุล : นางสาวณัฐรินีย์ แพประสิทธิ์
รหัสนักศึกษา : 6810110102

ระบบเว็บแอปพลิเคชันสำหรับร้านดอกไม้ที่ช่วยให้ลูกค้าสามารถ **"ออกแบบช่อดอกไม้ด้วยตัวเอง"** ตั้งแต่เลือกขนาดช่อ ชนิดดอกไม้ สไตล์การห่อ ไปจนถึงการสรุปยอดชำระเงินอย่างแม่นยำ

## คุณสมบัติเด่น (Features)
* **Smart Bouquet Sizing:** ระบบเลือกขนาดช่อ (เล็ก, กลาง, ใหญ่) พร้อมกำหนดเกณฑ์จำนวนดอกไม้ที่เหมาะสม
* **Interactive Flower Selection:** หน้าเลือกดอกไม้แบบ Horizontal Scroll พร้อมปุ่มลูกศรควบคุม และตัวนับจำนวนดอกไม้แบบ Real-time
* **Live Price Calculation:** ระบบคำนวณราคาสุทธิโดยรวมค่าธรรมเนียมจัดช่อและราคาดอกไม้แต่ละชนิดตามจริง
* **Delivery & Summary:** ระบบกรอกข้อมูลจัดส่งและหน้าสรุปรายการสั่งซื้อที่ละเอียดครบถ้วน
* **User Authentication:** ระบบสมัครสมาชิกและเข้าสู่ระบบ พร้อมการตรวจสอบความปลอดภัยของรหัสผ่าน
* **Order History:** ระบบจัดเก็บและแสดงประวัติการสั่งซื้อย้อนหลังพร้อมรูปภาพดอกไม้ที่เลือก

##  เทคโนโลยีที่ใช้ (Tech Stack)
* **Backend:** Python Flask
* **Database:** SQLite (จัดการผ่าน Flask-SQLAlchemy)
* **Frontend:** HTML5, CSS3 (Bootstrap 5), JavaScript (Vanilla JS)
* **Timezone:** PyTZ (สำหรับจัดการเวลา Asia/Bangkok)



##  วิธีการติดตั้งและรันโปรเจกต์ (Installation)

1. **ติดตั้ง Library ที่จำเป็น:**
   Bash
   pip install flask flask-sqlalchemy pytz

2. **ร้างโฟลเดอร์ที่สำคัญ:**
/static/images/flowers/ : สำหรับรูปดอกไม้ (1.png - 19.png)
/static/images/bouquet_sizes/ : สำหรับรูปขนาดช่อ (small.png, medium.png, large.png)
/templates/ : ไฟล์หน้าเว็บ HTML ทั้งหมด

3. **เริ่มใช้งานระบบ:**
Bash
python app.py
ระบบจะสร้างไฟล์ database.db ให้โดยอัตโนมัติเมื่อรันครั้งแรก
เข้าใช้งานผ่าน Browser ที่: http://127.0.0.1:5000

เกณฑ์การจัดช่อ (Bouquet Rules)
ขนาดช่อ,จำนวนดอกไม้ที่กำหนด,ค่าธรรมเนียมจัดช่อ
ช่อเล็ก,5 - 9 ดอก,200 ฿
ช่อกลาง,10 - 19 ดอก,300 ฿
ช่อใหญ่,20 - 39 ดอก,500 ฿
